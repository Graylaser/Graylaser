# Personal Profile Card Example

This is a simple example of a personal profile card - perfect for beginners learning HTML and CSS!

## What This Project Demonstrates

- Using HTML structure (divs, headings, paragraphs, links, images)
- Basic CSS styling (colors, fonts, spacing)
- CSS box model (padding, margin, borders)
- Creating hover effects
- Centering elements
- Making a visually appealing card design

## Files Included

- `index.html` - The HTML structure
- `style.css` - All the styling

## How to View

1. Download both files to the same folder
2. Open `index.html` in your web browser
3. That's it!

## Customization Ideas

Try customizing this project by:
- Replacing the placeholder image with your own photo
- Changing the colors (try different color schemes!)
- Modifying the fonts
- Adding more social media links
- Changing the background gradient
- Adding icons to the social links

## Skills You'll Practice

- HTML structure
- CSS styling
- Working with colors
- Creating layouts
- Adding hover effects
- Using gradients

## Next Steps

After completing this project, try:
- Making it responsive (works on mobile)
- Adding animations
- Creating multiple cards in a grid
