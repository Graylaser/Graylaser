# 🚀 HTML & CSS Mini Projects for Beginners

Welcome! If you've learned HTML basics (links, fonts, colors, images, lists) and a bit of CSS, you're ready to build some fun mini projects! Here are project ideas organized by difficulty level.

---

## 📝 Beginner Projects (Start Here!)

### 1. Personal Profile Card
**What you'll build:** A single card displaying your photo, name, and social media links.

**Skills you'll use:**
- Images (`<img>`)
- Links (`<a>`)
- Basic CSS styling (colors, fonts, borders)
- CSS Box model (padding, margin)

**What you'll learn:**
- Centering elements
- Creating hover effects
- Using CSS to make cards visually appealing

**Estimated time:** 1-2 hours

📁 **[View Example Code](./examples/personal-profile-card/)** - Start with this working example!

---

### 2. Simple Landing Page
**What you'll build:** A one-page website with a header, hero section, and footer.

**Skills you'll use:**
- Headings (`<h1>`, `<h2>`)
- Paragraphs (`<p>`)
- Images
- Links
- CSS colors and fonts
- Background colors/images

**What you'll learn:**
- Page layout structure
- Using semantic HTML
- Styling different sections
- Creating a hero section with background

**Estimated time:** 2-3 hours

---

### 3. Recipe Page
**What you'll build:** A page displaying a recipe with ingredients and instructions.

**Skills you'll use:**
- Lists (`<ul>`, `<ol>`, `<li>`)
- Images
- Headings
- CSS styling
- Text formatting

**What you'll learn:**
- Organizing content with lists
- Styling text for readability
- Adding recipe images
- Creating print-friendly layouts

**Estimated time:** 1-2 hours

---

## 💡 Tips for Success

1. **Start Small:** Begin with Project #1 and work your way up
2. **Use Real Content:** Use your own photos, information, and favorite recipes
3. **Experiment:** Try different colors, fonts, and layouts
4. **Check Your Code:** Use browser developer tools (F12) to inspect and debug
5. **Be Creative:** Make each project unique and personal
6. **Save Your Work:** Use GitHub to save your projects
7. **Get Inspiration:** Look at other websites for design ideas (but build from scratch!)

## 📈 Next Steps After These Projects

Once you complete these mini projects, you'll be ready to:
- Learn CSS Flexbox and Grid in depth
- Explore responsive design (media queries)
- Add JavaScript for interactivity
- Build more complex multi-page websites
- Learn CSS animations and transitions
- Explore CSS frameworks (Bootstrap, Tailwind CSS)

## 🎯 Project Structure Tip

For each project, create a folder with:
```
project-name/
  ├── index.html
  ├── style.css
  ├── images/
  │   └── (your images here)
  └── README.md (optional: notes about your project)
```
